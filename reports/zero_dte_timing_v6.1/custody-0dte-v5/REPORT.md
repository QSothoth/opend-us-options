# 评测报告：zero_dte_timing_v6.1

**结论：REJECT** —— 没达到标准，不能上线。

**综合分：40.9 / 100**（对照组 28.5；按交易日重抽样 95% 区间 25.7 ~ 61.6，比对照组高 -1.9 ~ +37.4 分；上游方向对 60% 时 44.5，对照组 34.2）。综合分用来比较版本和挑选候选，结论仍只看门槛。

## 先看这里：这份报告在比什么

1. **怎么算一笔**：对数据集里的每一张合约，用当天真实的 1 分钟行情从开盘逐分钟回放。策略说「买」之后，用下一根有成交的期权 K 线的价格买入（再往不利方向多付该 K 线振幅的 25%，并扣每张 $0.65 手续费），卖出同理。收益 = 这一笔赚的钱 ÷ 买入时付的权利金。
2. **对照组**：同一张合约，用「不择时」的笨办法再算一遍——09:35 直接买入，拿到 15:45 卖出。择时策略存在的意义就是要比这个笨办法好；比不过，就说明择时没有用。
3. **为什么 CALL 和 PUT 要一起验证、要「方向对错各半」来算平均**：每个标的每天应当同时评测同一行权价的 CALL 和 PUT，这样当天无论涨跌，方向对和方向错的合约各占一半，结果和上游选方向的对错无关。本数据集两边齐全。这份数据集里方向错的合约 53 张、方向对的 53 张（其余是震荡）。如果直接平均，哪个策略砍仓快哪个就显得好，比的其实是数据集而不是择时。所以把「方向对的日子」和「方向错的日子」各按一半权重平均，相当于假设上游选方向一半对一半错。
4. **举例**：US.SPY 2026-08-18 CALL —— 策略 10:34 买、10:47 卖（止损），收益 -34.3%；对照组收益 -96.6%。

数据集：`custody-0dte-v5`，126 张合约 / 20 个交易日（2026-08-18 → 2026-09-15）；策略参数截止 `2026-09-16` 的数据设计，之后的交易日才算样本外。

## 4. 结果靠不靠得住

- **随机时点对照**：把策略的买卖时间随机换到别的合约上，重复 1000 次。随机时间的平均收益不比策略差的比例 p = 0.67，盈亏比 p = 0.00。p 越小越说明择时真的用上了当天走势；p 大于 0.1 基本等于没有择时能力。
- **按交易日重抽样 1000 次的 95% 区间**：策略平均每笔 -19.5% ~ -2.1%，盈亏比 1.46 ~ 3.86；策略减对照组的平均收益 +1.8% ~ +27.2%（区间跨过 0 说明还不能确定比对照组好）。
- **假设上游方向对 60%**：策略平均每笔 -9.2%、盈亏比 2.41；对照组平均每笔 -14.2%。
- **前后两半**：前一半（2026-08-18 → 2026-08-31）策略平均 -8.7% / 对照组 -30.1%；后一半（2026-09-01 → 2026-09-15）策略平均 -13.5% / 对照组 -24.3%。
- **去掉任意一天**：共 20 次，全部仍赢对照组。
- **参数上下浮动 25%**：共 39 组，全部仍赢对照组。
- **不算滑点**：策略平均每笔 -7.7%、盈亏比 2.60；对照组平均每笔 -22.0%。
- **滑点加倍（让出振幅 50%）**：策略平均每笔 -14.8%、盈亏比 2.11；对照组平均每笔 -29.5%。
- **成交再晚 1 分钟**：策略平均每笔 -9.8%、盈亏比 2.83；对照组平均每笔 -25.7%。

完成情况：完成买卖 107；无入场信号 19；买入未成交 0；卖出未成交（到期结算） 0
