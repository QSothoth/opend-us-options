The implementation is independently written. Its OHLCV profile and BB/KC squeeze variant are explicitly labeled and should not be represented as a tick-level profile or an exact proprietary TTM clone. Published volume profile documentation also distinguishes bar up/down volume from actual aggressor buy/sell volume.
