# 策略说明（STRATEGY）

当前唯一策略：**`zero_dte_timing_v1`**（引擎 `zero_dte_timing`，状态 `candidate`）。
代码 `custody/engines/zero_dte_timing.py`，参数 `custody/strategies/zero_dte_timing_v1.json`，报告 `reports/zero_dte_timing_v1/custody-train-0dte/REPORT.md`。

## 0. 这个策略是怎么来的

它**不是**用数据「训练」或者「搜参数」搜出来的，而是先按买期权亏钱的规律定规则，再用 V4 检查。

1. **先量期权怎么跟着正股动**（在 V4 上实测）：上午平值 0DTE 的权利金大约等于正股 1.5 个「1 分钟平均波幅」（ATR）。
   正股反向走 1 个 ATR，期权大约亏 20%–30%；15–30 分钟内顺向走 4 个 ATR 以上，期权大约涨 90%–100%。
   这决定了止损放多远（1–2 个 ATR ≈ 亏 30%–45%）、赚多少之后开始跟踪（3 个 ATR）。
2. **按买方最怕的两件事定规则**：方向错了还拿着、价格不动被时间价值磨掉。于是有了：等走势确认再买、有止损、20 分钟不涨就走、
   赚了才跟踪、到 13:00 还没买就必须买（保证一天一笔）、15:45 前卖掉。
3. **指标周期用常见值**：EMA 9/21、ATR 14、开盘区间 15 分钟，没有调过。
4. **用评测标准在 V4 上跑一遍**，结果见第 7 节。
5. **针对看到的问题试了 12 个改动**（第 8 节全部列出），都没有更好，所以保留第一版。

所以它是一个有道理的起点，不是证明过能赚钱的策略，V4 上的评测结论是 REJECT。

## 1. 思路

买入末日期权的钱主要亏在两处：**方向错了还拿着**，以及**没走出来之前被时间价值磨掉**。
所以策略不在开盘就付权利金，而是等当天走势先确认上游给的方向；确认后给一个有限的止损，
迟迟不走就离场，真正走出来了才放宽、跟踪，不设止盈上限。

所有价格都按方向取符号：对 CALL「涨」是有利，对 PUT「跌」是有利。下文的「上方 / 突破 / 回落」都指有利方向。

## 2. 输入输出

- 输入：当天已完成的正股 1m K 线（逐根）、方向、当日开收盘时间；入场成交后平台告知成交时间和正股价格。
- 输出：每根 K 线一个动作 `WAIT` / `ENTER` / `HOLD` / `EXIT` 及原因。
- 不看期权价格、不看昨天、不看日线。

## 3. 入场

开盘区间（前 `opening_minutes` 分钟）内不入场。之后在第一根同时满足以下三条的 K 线入场：

1. **VWAP 同侧**：收盘价在 VWAP 有利一侧至少 `vwap_buffer_atr` 个 ATR；
2. **趋势**：快 EMA 在慢 EMA 有利一侧（差值 ≥ `trend_buffer_atr` ATR），且快 EMA 仍在朝有利方向走；
3. **新突破**：收盘价超过前 `momentum_lookback` 根 K 线的最高价（有利方向）。

入场原因：开盘后曾反向走出超过一个开盘区间高度，记为 `reversal_reclaim`；否则 `trend_breakout`。

开盘后 `relax_after_minutes` 分钟起，条件放宽为「新突破 + (VWAP 同侧 或 趋势)」，原因 `late_confirmation`。
距收盘 `must_enter_before_close_minutes` 分钟时仍未入场则**无条件入场**（`must_trade_deadline`），保证每天一笔。

## 4. 出场

风险单位是入场决策时冻结的 1m ATR。

| 规则 | 触发 | 原因 |
|---|---|---|
| 失效止损 | 收盘价跌破止损线。止损距离 = 入场价到最近 `stop_lookback` 根 K 线最低点的距离，限制在 [`stop_min_atr`, `stop_max_atr`] ATR 之间 | `invalidation_stop` |
| 保本 | 最佳收盘价曾领先 `breakeven_at_atr` ATR 后，止损线上移到入场价 | `breakeven_stop` |
| 跟踪 | 最佳收盘价曾领先 `trail_activate_atr` ATR 后，止损线跟随最佳收盘价回撤 `trail_atr` ATR；不设止盈 | `trailing_stop` |
| 无进展 | 持仓满 `fail_minutes` 分钟、最佳领先不足 `fail_progress_atr` ATR、且当前不高于入场价 | `no_progress` |
| 强平 | 距收盘 `flatten_before_close_minutes` 分钟 | `scheduled_flatten` |

所有止损只看已完成 1m K 线的收盘价。

## 5. 各种日内形态下的行为

| 形态（对所选方向） | 策略行为 |
|---|---|
| 顺势单边（含跳空后一路走） | 开盘区间结束后很快满足三条件入场；趋势持续则跟踪持有 |
| 先逆后顺（CALL 的「低开 / 先跌后涨」） | 下跌段价格在 VWAP 下方、EMA 向下，不入场；收复 VWAP 并出现新高后入场 |
| 先顺后逆（CALL 的「高开 / 先涨后跌」） | 前段可能已入场；反转时由失效止损或保本止损离场 |
| 逆势单边 | 始终不满足条件，不提前付权利金；到截止时刻入场，由止损 / 无进展尽快离场 |
| 震荡 | 三条件同时满足的次数少；进场后多由无进展或失效止损小亏离场 |

## 6. 参数（v1）

| 参数 | 值 | 参数 | 值 |
|---|---:|---|---:|
| `ema_fast` / `ema_slow` | 9 / 21 | `stop_lookback` | 10 |
| `atr_period` | 14 | `stop_min_atr` / `stop_max_atr` | 1.0 / 2.0 |
| `opening_minutes` | 15 | `fail_minutes` / `fail_progress_atr` | 20 / 1.0 |
| `momentum_lookback` | 5 | `breakeven_at_atr` | 2.0 |
| `vwap_buffer_atr` / `trend_buffer_atr` | 0.25 / 0.0 | `trail_activate_atr` / `trail_atr` | 3.0 / 2.5 |
| `relax_after_minutes` | 120（11:30） | `must_enter_before_close_minutes` | 180（13:00） |
| `flatten_before_close_minutes` | 15（15:45） | | |

这些是按期权对正股波动的敏感度设定的初值，不是搜参结果。V4 上实测：上午平值 0DTE 权利金约为 1.4–1.8 个 1m ATR，
正股反向 1 个 ATR 期权约 −20%~−30%，15–30 分钟内顺向 4 个 ATR 以上期权约 +90%~+100%。

## 7. V4 评测结果（`custody-train-0dte`，结论 REJECT）

| 方向对错各半计算 | 策略 | 对照组（09:35 买，拿到 15:45） |
|---|---:|---:|
| 平均每笔收益 | −22.3% | −37.0% |
| 盈亏比 | 1.40 | 2.32 |
| 平均盈利 / 平均亏损 | 53.3% / 38.0% | 187.6% / 81.0% |
| 逆势单边平均（19 个） | −49.2% | −98.5% |
| 先逆后顺平均（8 个） | +12.5% | −64.8% |
| 震荡平均（6 个） | −39.3% | −81.5% |
| 顺势单边平均（2 个） | −26.1% | +82.2% |

- 通过：G1 每张都完成一买一卖、G2 没有偷看未来、G3 平均收益好于对照组、G5 方向错时亏得更少、G6 方向对时平均赚钱（+4.8%）。
- **未通过 G4：盈亏比 1.40 < 2**。另外场景覆盖不足、没有样本外数据。
- 随机时点对照：平均收益 p = 0.82、盈亏比 p = 0.27，在 V4 上看不出择时比随机挑时间更好。
- 成交压力：不算滑点时平均 −16.7%、盈亏比 1.70；成交再晚 1 分钟时盈亏比降到 0.70，对延迟敏感。

**解读**：策略做到了「方向错了少亏」（逆势单边从 −98% 降到 −49%），但「方向对了拿住」还不够——
顺势单边只有 2 个样本，其中 SPY 08-20 的 PUT 被跟踪止损提前带出（−9%，持有是 +206%），而一天只能做一笔，出场后就错过了整段行情。
V4 的方向偏差让它几乎无法区分择时规则的优劣，下一步的关键是 V5 的两边数据和样本外交易日，而不是继续在 V4 上调参。

## 8. 研究记录（V4 上尝试过的全部变体）

为避免过拟合，只试了少量有明确理由的结构变化，全部列出。数值按方向对错各半计算；「平均」= 平均每笔收益，「顺向」= 顺势单边 + 先逆后顺，「逆势」= 逆势单边。

| 变体 | 改动 | 平均 | 盈亏比 | 顺向 | 逆势 | 震荡 |
|---|---|---:|---:|---:|---:|---:|
| **v1（采用）** | 第 6 节参数 | **−22.3%** | **1.40** | +4.8% | −49.2% | −39.3% |
| A | 止损放宽到 1.5–3 ATR，无进展 30 分钟，保本 3 ATR，跟踪 4/4 ATR | −42.1% | 2.09 | −36.4% | −64.4% | −45.3% |
| B | A + 盈利 3 ATR 后改为跌破慢 EMA 才离场 | −25.7% | 1.31 | −6.1% | −51.4% | −45.3% |
| C | B + 强制入场提前到 11:30 | −27.0% | 1.26 | −6.2% | −52.6% | −50.8% |
| D | B + 取消放宽入场 | −29.6% | 1.18 | −9.2% | −61.4% | −48.2% |
| E | 只留失效止损，盈利单持有到强平 | −51.1% | 1.09 | −47.5% | −61.7% | −40.7% |

- 「盈利单拿到收盘」（E–I）全部更差：0DTE 的趋势很少持续到收盘，时间价值吞掉了回吐。
- P1–P3 需要期权价格作为信号，违反输入规范；而且只有 P3 略好，不足以改变规范，未采用。
- 另做过入场触发的前瞻收益诊断（突破确认 / 回踩续涨 / 仅 VWAP 同侧 / 反向 VWAP 与每 15 分钟随机时点对比），在 V4 上没有一种触发的方向对称加权前瞻收益稳定优于随机时点。

## 9. 如何写新策略

1. 在 `custody/engines/` 新建模块，实现 `custody/strategy.py` 里的契约：
   - `__init__(params, direction, session)`、`on_bar(bar) -> Decision`、`on_entry_filled(at, underlying_mark)`；
   - 类属性 `validate = staticmethod(validate_params)`，严格校验参数（未知 / 缺失 / 越界都报错）；
   - 必须支持 `must_enter_before_close_minutes`、`flatten_before_close_minutes` 两个参数。
2. 在 `custody/engines/__init__.py` 的 `ENGINES` 里登记引擎名。
3. 新建 `custody/strategies/<strategy_id>.json`（`schema_version`、`strategy_id`、`engine`、`status: candidate`、`description`、`developed_on`、`params`），把文件 SHA256 写进 `index.json`。改参数永远是新 id。
4. 写单元测试（`custody/tests/`），至少覆盖：各场景的入场 / 出场行为、多空镜像一致、前缀回放一致、参数校验。
5. `python3 -m custody evaluate --dataset data/custody-train-0dte --out reports/<strategy_id>/custody-train-0dte`，把报告和尝试过的变体记录一起提交。
6. 要把默认策略换成新策略：改 `index.json` 的 `default`，旧策略改为新文件 id 或保留原状（已注册文件不可修改）。
