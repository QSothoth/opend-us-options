# s-alpha

**S Alpha** — 多市场策略实验仓。当前主线是美股末日期权（0DTE）单笔择时；港股近月期权流量已在 `studies/`；A 股 / 盘中策略以后按需加，未实现的不在此宣称。

当前主线细节：**末日期权（0DTE）单笔择时。**上游选好标的、方向和当天到期的合约后，本项目只决定这一张期权当天何时买、何时卖：
每张合约当天争取完成一笔、最多一笔；无信号可以不交易，完成分占综合分的 20%（同一标的可以同时有做多和做空的合约），信号只看当天正股 1 分钟 K 线，盈亏按期权成交价计算，目标是放大盈亏比。

项目规范（Release、训练数据、策略与评测的约定）见 **[AGENTS.md](AGENTS.md)**（`CLAUDE.md` 引用此文件）。

## 快速开始

```bash
# 测试（仅标准库，不连 OpenD）
python3 -m unittest discover -s custody/tests

# 查看注册状态；数据下载与哈希校验见 docs/DATA.md
python3 -m custody strategies

# 下载后离线评测，显式指定策略，避免默认值与报告目录错配
python3 -m custody evaluate --strategy zero_dte_timing_v6.5 \
  --dataset data/custody-0dte-v6.1 --out reports/zero_dte_timing_v6.5/custody-0dte-v6.1
```

数据获取、每日冻结及发布只按 [数据流程](docs/DATA.md) 操作；盘中观察见 [dryrun](docs/RUNTIME.md#4-dryrun)，模拟账户与实盘下单见 [run](docs/RUNTIME.md#5-run)。所有命令：`python3 -m custody`。
只有单边的数据 `custody check` 会以非零退出码拒绝发布；离线评测允许它做诊断。

- **已知问题**：用户 2026-09-18 实盘发现 SNDK 单边上涨（+10.25%）全天没有买入信号。逐分钟回放确认，09:46 时 v6.5 其他条件都满足，只被 v6.4 引入的「突破要来自波动压缩」（`squeeze_lookback`）挡住；之后全天被「不追离开 VWAP 超过 2 ATR」（`max_vwap_atr`）挡住。没有这两条过滤的 v6.1 / v6.2 / v6.3 都在 09:50 买入并拿到 +135.9%。验证集当天对照组涨幅最大的三张（SNDK CALL +184.9%、GOOGL PUT +305.4%、META PUT +98.6%）v6.5 一张都没买。诊断与影响面见 [策略说明](docs/STRATEGY.md#sndk-2026-09-18-没出买入信号的诊断)。
- 研究轮次 [R17](docs/STRATEGY.md#研究轮次-r172026-09-20运行前登记)（2026-09-20，运行前登记）针对上面的漏单问题检验压缩过滤，胜出候选注册为 **v6.6 = v6.5 把压缩回看窗口 10 放宽到 30**（`candidate`，默认策略仍是 v6.5）。它是换数据集后第一个训练集 G3–G12 全部通过的版本：综合分 74.7（对照组 38.2）、平均 +4.2%、盈亏比 4.55、利润因子 1.35、方向对时参与 47/63；留一天交叉验证 21 折里 19 折选中它，相对 v6.5 的综合分差 95% 区间 +0.8 ~ +16.9 不跨零。验证集那一天 61.1，略差于 v6.5 的 62.2。完全去掉压缩过滤（候选 Z1）则整体亏钱，G11 G12 未通过。
- **R17 没有解决 SNDK 那类漏单**：整天不出现压缩的行情里判据一直是「没见过压缩」，放宽回看窗口不改变这一点，v6.6 当天同样没买 SNDK / GOOGL PUT / META PUT。
- [R18](docs/STRATEGY.md#研究轮次-r182026-09-20运行前登记) 与 [R19](docs/STRATEGY.md#研究轮次-r192026-09-20运行前登记) 按用户要求改找通用解法（不为单个 case 拟合），两轮都按预登记规则**失败**，v6.6 保留：放宽止损距离无效（那些单只是改由别的规则以相近价格卖出），放宽保本止损与无进展退出虽然让方向对时多赚约 3 个百分点，却把盈亏比从 4.55 压到 3.00–4.29，整体更差。另有两条被否定的路线：按入场时 1m ATR 占价格的比例过滤（实为挑标的），以及放开压缩判据在第 15–19 分钟的计算盲区（那批交易平均 −17.9%）。**SNDK 那笔漏单在统计上是正确决策。**
- [R20](docs/STRATEGY.md#研究轮次-r202026-09-20运行前登记) 按用户要求单独重测「不追离 VWAP 太远」这条规则（含把分母从会随趋势收缩的 1m ATR 换成开盘区间高度的新口径），同样**失败**：五个候选参与率都大幅提高（方向对参与 47/63 → 最高 61/63），但顺势单边收益无一超过基线，盈亏比从 4.55 掉到 3.51–3.86。放宽后确实买到了 SNDK（+50.9%，买入持有 +184.9%），但多买的 29 笔合计 −156.6 个百分点，其中顺势单边 12 笔平均只有 +2.0%——**追高买入的单即使方向对也几乎不赚钱**。
- 判断：当前引擎框架内的参数空间已被 R10–R20 反复搜索，**v6.6 接近该框架的局部最优**；R18 / R19 / R20 三轮失败方向一致——每一次放宽限制都让参与率上升、盈亏比和综合分下降。SNDK 那类漏单不是可单独修掉的缺陷，而是这套策略赚钱方式的组成部分。下一步是积累真正的样本外交易日（门槛要求 20 个）来检验 v6.6，而不是再调参数。
- 比较版本看 [综合分](docs/STANDARD.md) = 收益分 × 80% + 完成分 × 20%；收益分由盈亏比、利润因子、方向对 / 不利时的表现构成，未入场按 0 收益计入，结论仍只看门槛。
- **第二条策略线：保证入场线（2026-09-20，用户决定，版本号 `open_hold_*` 独立管理）**。唯一硬约束是**开盘 1 小时内必须买入一单**，用于某些标的上「宁可买错也要建仓」的场景；在这个约束下入场时刻与方式都可调。它不适用「优于对照组」的门槛，改按[盈亏平衡命中率](docs/STANDARD.md#9b-不择时执行策略的判定open_hold-引擎2026-09-20-起)判定，结论最高 PROVISIONAL，不得用于 `--mode live`。
  - **[`open_hold_v3`](docs/STRATEGY.md#研究轮次-r232026-09-20运行前登记保证入场线的离场强度)（R23，这条线目前最好的配置）**：v6.6 的入场信号 + 60 分钟兜底，离场**只保留翻倍止盈与浮盈回落锁盈**，解除止损、保本、无进展、跟踪与 charm 退出。训练集盈亏平衡命中率 55.1%、75% / 85% 命中率下每笔 +24.5% / +36.8%；**留一天交叉验证 21 折全部选中它，样本外估计 55.09% 与全样本一致**；验证集 61.6%。代价是最差一笔 −104.3%、32% 的 case 亏掉九成以上。
  - [`open_hold_v2`](docs/STRATEGY.md#研究轮次-r222026-09-20运行前登记保证入场线窗口内择时-vs-固定时刻)（R22）：同样的入场，但用 v6.6 的全套离场。**唯一优势是尾部风险为零**（亏九成以上 0/146，最差 −84.9%），适合完全不能承受单笔全损的场景；收益远低（75% / 85% 下 +4.6% / +7.3%），且样本外估计不盈亏平衡。
  - [`open_hold_v1`](docs/STRATEGY.md#研究轮次-r212026-09-20运行前登记不择时执行策略-open_hold)（R21）：09:31 固定买入、持有到底，不做任何决策。三个口径一致（72.8 / 76.4 / 63.0），但 v3 在两个参考点上都优于它，保留作为对照。
  - R23 的关键机制：**在必须建仓的前提下，止损类规则会退化**——这条线有 90/146 的仓位是无信号兜底买入的，止损、保本、无进展的前提（「入场有理由，理由失效就走」）对它们不成立，于是按噪声随机平仓，砍掉的恰是唯一能抵消兜底亏损的大行情。只留止盈不会误伤尚未启动的仓位。
  - [R24](docs/STRATEGY.md#研究轮次-r242026-09-20运行前登记保证入场线的入场过滤强度) 与 [R25](docs/STRATEGY.md#研究轮次-r252026-09-20运行前登记晚入场是真有价值还是选择效应) 都**失败**，v3 保留：放宽入场过滤单调变差（越松越差，全部按固定时刻买最差）；把晚入场强加到所有交易日也更差。R25 另确认**第 60 分钟兜底是内点最优**（45 分钟 56.2%、60 分钟 55.1%、75 分钟 58.8%、90 分钟 60.3%），**你的「1 小时内必须买入」约束恰好落在最优点上**，放宽它不会改善。
  - [R26](docs/STRATEGY.md#研究轮次-r262026-09-20运行前登记保证入场线的止盈与锁盈参数) 同样失败：止盈门槛向上（2.0）向下（0.5）都更差，**确认 1.0 是真正的最优点**而非从择时线继承的任意值。**六个维度（入场时刻、兜底时刻、离场强度、入场过滤、晚入场因果、止盈水平）全部搜索完毕，`open_hold_v3` 是这条线在当前引擎与数据下的局部最优，参数搜索到此结束。**
  - 一个跨轮的发现：**离场规则决定了入场时刻的最优点**。纯持有时越早买越好（R21，09:31 最优）；止盈 + 锁盈时越晚买越好（R25，第 60 分钟最优）——因为止盈会提前了结浮盈，早买的优势被截断，买得便宜反而更重要。
  - ⚠️ **数据完整性**：R23 的首次探索误把验证集与训练集合并计算，虽随即只用训练集重做选择，但**验证集对 `open_hold` 线已不再是干净的留出集**，其数值只作描述。这条线要取得真正的样本外证据，需用 2026-09-18 之后新冻结的交易日。择时主线不受影响。
- 下一步每天冻结同一行权价的 CALL / PUT，积累样本外交易日；验证集不得用于调参。**上游方向命中率目前没有独立估计**，而它决定两条策略线怎么选，建议用 paper 模式并行记录。
- `custody run` 通过 OpenD 下单：`--mode paper` 用模拟账户，`--mode live` 只接受 accepted 策略；dryrun 只读行情、记录模拟成交。

## 安全

- 不提交 `.env`、OpenD 登录 / 交易密码、WxPusher SPT、运行数据库。
