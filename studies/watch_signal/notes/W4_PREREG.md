# W4 预登记：分钟资金流能否给出 30 分钟方向（数据尚未采集）

登记时间：2026-09-24，**采集开始当天、任何检验之前**。写好后不改。

## 数据

`code/capture_flow.py` 每个交易日收盘后抓取：港股通 ∩ 已扣费标的（当前 140 只）的 `get_capital_flow(INTRADAY)`
（每分钟累计的主动净流入 `in_flow`，以及超大 / 大 / 中 / 小单四档），和同日 1m K 线（只拉已扣费标的，零额度）。
存到 `data/flow/`，不进 git。错过的交易日补不回来。

- **选择段**：采集到的前 20 个交易日。
- **验证段**：其后至少 20 个交易日。验证段只评测一次。

## 定义

对每只标的每分钟：`imb15 = Δ15(in_flow) / Σ15(turnover)`（最近 15 分钟净主动买入额占成交额的比例，−1～1）；
`big15` 同理只用 `super_in_flow + big_in_flow`；`sml15` 只用 `sml_in_flow`。
只评测 `tpb ≥ 2` 的标的-日（与盯盘价位闸一致）。结果口径 d1f30（下一根收盘入场、30 根后平），多空对称 `bal`，t 按交易日聚类。
信号去重同盯盘：同方向 15 根内不重复，开盘前 25 根不发。

## 候选（5 个）

| id | 规则 |
|---|---|
| F1 | `imb15 > 0.2` → BUY，`< −0.2` → SELL |
| F2 | `big15 > 0.2` → BUY，`< −0.2` → SELL |
| F3 | 大单与小单背离：`big15 > 0.1` 且 `sml15 < −0.1` → BUY，反之 SELL |
| F4 | F1 取反（资金流过度 → 反转） |
| F5 | 盯盘现有标注中，只保留 `imb15` 与标注同向（`imb15 × side > 0`）的 |

## 选择与判定

选择段上取 `bal` 的按日聚类 t 最大者（要求密度 ≥ 1 个 / 标的-日，F5 除外）。验证段门槛（全部满足才进盯盘）：

1. `bal` > 0 且 t ≥ 2；
2. BUY、SELL 两侧均值都 > 0；
3. 方向命中 ≥ 52%；
4. F5 被选中时，还要求被过滤掉的标注 `bal` 低于保留的。

失败也写进 `reports/`。
