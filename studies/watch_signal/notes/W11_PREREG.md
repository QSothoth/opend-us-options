# W11 预登记：表头「日线偏向」= 逆近 5 日（周度反转），不依赖盘中触发

登记时间：2026-09-24，运行之前。写好后不改。

## 假设

W6 在三段数据上都显示「逆近 5 日」的标注更好。若效应来自日线层面的周度反转（Lehmann 1990；Jegadeesh 1990），
那么不需要盘中触发：开盘后直接按 `−sign(近 5 日涨跌)` 定当天偏向，持有到收盘也应为正。

## 规则（无参数）

偏向 `s = −sign(close[D−1] / close[D−6] − 1)`；入场 09:31 那根收盘（第一根连续交易），持有到 15:59 收盘。每标的每天一次。

## 口径与判定

多空对称 `bal`，t 按交易日聚类；主评估价位细（tpb ≥ 2，按当天中午的 tpb 分类），`~` 只报告。
三段数据都报告；**判定只看「没有参与任何挑选」的合并段**（2025-06 → 11 与 2026-08-17 → 09-23；
严格说这两段在 W6 复核里看过「逆 5 日」对标注的作用，但没有看过这条独立规则）：

1. `bal` > 0 且 t ≥ 2；
2. BUY、SELL 两侧均值都 > 0。

通过则在盯盘表头显示「日线偏向」；不通过则不显示，只在 README 记录。
