# W7 预登记：新信号类型「价位反应」（触及关键价位后收回 / 失败突破）

登记时间：2026-09-24，**任何运行之前**（没有做候选前探索）。写好后不改。

## 来源与结构性理由

- `research/last30days-0dte-experts`：@shentrades「别追已经走出的行情；价格碰到盘前标好的价位、出现拒绝就进，几分钟内离场」；
  盘前清单标「昨日高低点」；@trend_delta「30 分钟开盘区间向上突破后收回区间内」做反向。
- W6：突破昨日高 / 低点的顺势标注当天偏弱（选择段 −10.8bp、验证段 −20.5bp，持有到收盘）——关键价位附近「突破后不继续」是常态，
  那么「触及后收回」应当是有方向信息的事件。
- R10（美股 0DTE）探索过「失败的开盘区间突破反向入场」，按期权盈亏不行；这里是正股方向、港股，口径不同，照样如实检验。

## 价位

- `PDH` / `PDL`：前一交易日高 / 低（日 K，QFQ，同 W6）。
- `ORH` / `ORL`：当天 09:31–09:45 这 15 根 1m 的最高 / 最低（不含 09:30 竞价根），09:46 起才可用。

## 候选（5 个，新标注类型，与现有 `marks()` 无关）

| id | SELL 条件（BUY 镜像：用 PDL / ORL，方向反过来） |
|---|---|
| R1 | 影线拒绝 @PDH：`high ≥ PDH > close`，且上一根收盘 `< PDH` |
| R2 | 失败突破 @PDH：前 5 根内至少一根收盘 `> PDH`，本根收盘回到 `≤ PDH`（该段第一次收回） |
| R3 | 影线拒绝 @ORH（09:46 起） |
| R4 | 失败突破 @ORH（09:46 起） |
| R5 | R1–R4 任一 |

同方向 15 根内不重复；R1/R2 从 09:32 起可发。

## 口径

主口径 `f30`：下一根收盘入场、30 根后平（这类信号按原意是短线反应）。次口径 `fclose`（持有到收盘）。
多空对称 `bal`，t 按交易日聚类。主评估对象：价位细（tpb ≥ 2）的标的-日；`~`（tpb < 2）只报告。

数据：选择段 2025-12-01 → 2026-08-14；验证段 2026-08-17 → 09-23（只评测一次）。

## 选择规则

选择段、价位细，密度 ≥ 0.1 个 / 标的-日的候选中，取 `bal f30` 按日聚类 t 最大者。
另报告同段现有 `marks()` 标注的 `bal f30` 作参照。

## 验证门槛（价位细，全部满足才加进盯盘）

1. `bal f30` > 0 且 t ≥ 2；
2. `bal fclose` ≥ 0；
3. BUY、SELL 两侧 `f30` 均值都 > 0；
4. `bal f30` 高于同段现有标注的 `bal f30`。

通过则作为新的一类标注（字母用 `R`/`r` 区分）加进盯盘；不影响现有标注。
