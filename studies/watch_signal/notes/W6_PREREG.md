# W6 预登记：用日线层面的量价背景给盘中标注分「日线支持 / 不支持」

登记时间：2026-09-24，训练集探索之后、**验证集之前**。写好后不改。

## 来源与结构性理由

- `lowbuy-dip-scout` 里 TradingView 高手调研的教训：日线信息适合做**阶段 / 环境**判断而不是入场点；不要叠加指标；
  Kell 下降阶段过滤一度有效，修 bug 后消失——所以这里只用预先写死的简单规则，严格留出。
- 个股周度收益的短期反转（Lehmann 1990；Jegadeesh 1990）是文献里稳健的现象：短期超涨后续偏弱、超跌后续偏强。
- 训练集探索（`reports/daily_train_raw.txt`，价位细的标注，多空对称，持有到收盘）：
  标注方向与近 5 日涨跌同向的最高五分位 −16.9bp（t=−2.6），逆向的最低五分位 +11.5bp（t=+1.5）；
  顺日线均线排列 −10.2bp（t=−2.4），逆 +4.2bp；突破昨日高 / 低点 −10.8bp（t=−2.5），未突破 +2.4bp；
  10 日上涨量 / 下跌量比、离 20 日高低点距离给出同一方向。

## 数据

日线：140 只 + 恒指，OpenD `request_history_kline` K_DAY，2024-06-01 → 2026-09-23（已扣费标的，零额度）。
所有日线特征只用**前一交易日及更早**的收盘数据；昨日高低点在盘中与当前收盘价比较。
标注：盯盘当前全部标注（含 `~`），同 W2 的 `marks()`。

- 选择段：2025-12-01 → 2026-08-14。验证段：2026-08-17 → 09-23（28 天，只评测一次）。

## 候选（「支持」的定义，s = 标注方向 ±1）

| id | 支持 = |
|---|---|
| K1 | `s × 近 5 日涨跌 ≤ 0`（逆近 5 日走势） |
| K2 | `s × 日线阶段 ≤ 0`，阶段 = +1 若 收盘 > EMA10 > EMA20 > SMA50，−1 若全反，否则 0 |
| K3 | `s × log(10 日上涨日量 / 下跌日量) ≤ 0` |
| K4 | 标注那一刻未突破昨日高点（BUY）/ 昨日低点（SELL） |
| K5 | K1 且 K4 |

## 口径

主口径：持有到收盘（`fclose`，下一根收盘入场），多空对称 `bal` = (BUY 均值 + SELL 均值) / 2，t 按交易日聚类。
次口径：30 根（`f30`）。主评估对象：价位细（tpb ≥ 2）的标注；同时报告 `~` 标注。

## 选择规则

选择段、价位细标注上，「支持」组占比 ≥ 30% 的候选中，取「支持 − 不支持」的 `bal fclose` 差值按日聚类 t 最大者。

## 验证门槛（价位细标注，全部满足才进盯盘）

1. 「支持」组 `bal fclose` 高于「不支持」组，差值 t ≥ 2；
2. 「支持」组 `bal fclose` > 0；
3. `f30` 口径下「支持」组也不低于「不支持」组；
4. BUY、SELL 分开看，「支持」组的均值都高于各自「不支持」组（排除行情涨跌造成的假象）。

通过后的用法：盯盘标注后面加日线背景标记，**不删除任何标注**（与 `~` 同样的原则）。
