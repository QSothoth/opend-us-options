# HK-R3 预注册：去掉 theta 之后的「买方溢价」残差

写于 2026-09-20，在 R1 / R2 之后、跑 R3 之前。母体、指标、显著性、稳健性判定沿用
[R1](R1_PREREG.md)，不重复。

## 这一轮的地位（先说清楚，避免以后误读）

R2 的 D2（未被 delta 解释的期权涨幅 ≥ +10）方向为正但 n=12，**按 R1 的样本下限判为不达标**。
之后的事后诊断显示同一特征在全母体上 Spearman rho=+0.159（n=357，同日置换 p=0.0065），
五分位单调。**这个诊断是看过 R2 结果之后做的**，所以 R3 是「在同一批 30 天数据上把它
写成可执行规则」，不是独立验证。

**R3 的 p 值不可当作证据**：特征族是看过数据之后选的。R3 的产出只有一个——
一条定义明确、可以在**将来的样本外数据**上验证的规则。判定表照打，但结论一律写
「待样本外验证」，不得升级为「线索」以上。

## 结构性理由

`unexplained = 期权涨幅 − delta 能解释的部分` 整体偏负，是因为漏掉了近月期权每天确定性的
时间价值衰减（rank 数据里 theta / 期权价中位数约 **−10.5%/天**，与观测到的残差中位数一致）。
把 theta 减掉之后，残差 ≈ **买方为波动率多付的钱**：正值表示这一天的成交把期权价顶到了
delta + theta 之上。这才是「主动买盘」在只有成交量的数据里能留下的痕迹。

## 候选（3 个，跑完不加）

逐合约残差（成交额加权到标的日，裁剪 ±200 个百分点）：

```
prev_price = option_price / (1 + change_ratio/100)
residual   = change_ratio − 100 × (delta × (收盘 − 昨收) + theta) / prev_price
```

| ID | 规则 |
|---|---|
| E1 | 残差 ≥ 0（买方把价顶过了 delta + theta） |
| E2 | 残差在**当日母体横截面**里排前 20%（不依赖绝对阈值，每天都有信号） |
| E3 | E2 且该标的当日近月成交额中 DTE ≤ 5 的占比 ≥ 50% |

theta 取信号日收盘的快照（当日已知，不偷看未来），它是「昨日 theta」的近似。
