# HK-R1 预注册：用「相对流量」而不是「绝对成交额」筛近月 CALL

写于 2026-09-20，跑数之前。跑完不改规则，失败也记下来。

## 背景（已知事实，不是本轮结论）

- 数据只有 `dataset/` 里冻结的 CSV：`get_option_rank` **CALL only**，31 个交易日
  （2026-08-07 → 2026-09-18），每日成交额前 400 条；近月（DTE 0–14）1764 行。
- 正股日 K 只覆盖 40 个标的 → 可评测的近月标的日 **404 个 / 30 天**。
- 本机无 OpenD（11111 拒连、无 `futu`），本轮不拉新数据。

## 诊断（先于候选，只是描述数据）

用同日全 K 线面板的横截面均值做大盘因子，看**超额**收益：

| 群体 | T+1 n | 超额均值 | T+2 超额均值 |
|---|---:|---:|---:|
| 全部近月 CALL 标的日（universe） | 381 | −0.22% | −0.39% |
| 现行 aggressive（≥20 万 + 合计 ≥100 万） | 193 | **−0.45%** | **−1.03%** |

结论：旧报告说的「43% ≈ 掷硬币」不准确。扣掉大盘后，**按绝对成交额筛选比自己的母体还差**。
绝对金额只是在挑大盘股 + 高 beta，不含方向信息。

## 假设

近月 CALL 成交额的**绝对值**由标的市值和做市活跃度决定，没有方向信息；有方向信息的是
**相对自身基线的异常**、**是否新开仓**、**买的是不是彩票档**。所以本轮全部候选都必须是
尺度无关（scale-free）量，且只用信号日收盘前可知的信息。

## 候选（5 个，跑完不加）

母体 = 404 个近月 CALL 标的日（DTE 0–14、正股有日 K）。

| ID | 规则 | 结构性理由 |
|---|---|---|
| C1 | 标的近月 CALL 成交额 / 该标的前 5 个交易日同口径均值 ≥ 3 | 相对自身的异常放量才是信息 |
| C2 | 成交额加权的 volume/open_interest ≥ 1.0 | 新开仓主导，而非存量换手 |
| C3 | delta ≤ 0.25 的近月 CALL 占该标的当日成交额 ≥ 50% | 彩票档买盘＝押事件，不是对冲 |
| C4 | 领头合约成交额占该标的近月合计 ≥ 70% | 集中下注 vs 分散做市 |
| C5 | C1 且信号日收盘 ≥ 昨收（旧 `pi` 门控） | 检验「翻红」门控是否还能在相对流量之上加分 |

参数只取整数或常见值（3 倍、1.0、50%、70%），不做网格搜索。

## 判定规则（先写死）

1. 样本下限：T+1 可算样本 n ≥ 30，覆盖 ≥ 8 个不同交易日、≥ 6 个不同标的。不满足 = 无结论。
2. 主指标：**大盘调整后 T+1 超额均值**（对照 = 母体 −0.22%）；次指标 T+2。
3. 显著性：**同日内置换检验**（每个交易日内在母体里随机重排哪些标的被选中，保持每日信号
   个数），20000 次，报双向 p。置换保留大盘因子，只检验选股能力。
4. 稳健性，三条全过才算「线索」：
   - |超额均值| ≥ 0.5% 且 p ≤ 0.05；
   - 剔除 MiniMax（HK.00100）后符号不变；
   - 留一天交叉：任一单日贡献 < 总效应的 50%。
5. 只有 30 个交易日、1 个市场阶段，**结论最高只能是「线索 / PROVISIONAL」**，
   不得写成已验证的边，不得为 MiniMax 单票调参。
6. 若某候选显著为**负**，如实记录（它是反向筛子，不是买入信号）。
