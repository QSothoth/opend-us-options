# 盯盘

盘中只读 OpenD 行情，画走势 + 成交量 + 标注。**不下单。** 与 `custody` 主线（0DTE 择时）独立，不进策略注册表。

## 用法

```bash
/opt/futu-opend/venv/bin/python watch/smc_watch.py                          # 默认标的
/opt/futu-opend/venv/bin/python watch/smc_watch.py HK.02513 HK.09988 HK.01810
```

每个标的四行：走势曲线 / 成交量柱 / 买入标注 / 卖出标注。买卖分开两行，谁也盖不住谁——某一边一整天没信号会直接显示 `(无)`。标的名称从 OpenD 的 K 线帧直接取。

标注行的规则：一格约 6 分钟，同一格里**早的那个赢**（一波行情从哪里开始，比它还在继续更重要），带量的那个把格子升成大写。

管道输出（非 TTY）时不画看板，只打 JSON，方便 `| jq`。日志写 `watch/logs/<日期>.log`，每行带 `code`。

## 规则

**方向**（沿用最早那版）：`close` vs 当日 VWAP、EMA9/21、RSI14。

**触发**：

| 触发 | 含义 |
|---|---|
| `BOS` | 收盘突破左右各 3 根都确认的摆动点（结构突破） |
| `FVG` | 三根公允价值缺口，宽度 ≥ 0.25 × ATR14 |
| `SWEEP` | 影线扫穿确认摆动点后收回（流动性狩猎） |

**两档标注**：

| 档 | 条件 | 密度 | 看板上 |
|---|---|---|---|
| 普通 | 方向 + 触发 | 约 14 个 / 标的 / 天 | 小写 `b` `s`，暗色 |
| 带量 | 再加：当根量 ≥ 1.5 × 前 20 根均量，且在当日区间的顺位半区 | 约 1.2 个 / 标的 / 天 | 大写 `B` `S`，加粗 |

开盘前 25 根不标注，同方向同档 15 根内不重复。标注带 `失效`（多头取最近确认摆动低点）。

### 带量 ≠ 更准

**「带量」那档在每一个格子里都不优于「普通」档**，胜率、均值、盈亏比都是。它只是更罕见。

之前只用 3 个标的时曾量出带量档盈亏比 1.56（vs 普通 1.26），加入 MiniMax（HK.00100）之后这个优势消失——MiniMax 单独看：普通 -0.001%（盈亏比 1.19）、带量 -0.464%（盈亏比 0.79）。那次是 138 个样本上的噪声。

**所以「带量」标签说的是「触发时有量且位置顺」，不是「更可靠」。** 大写小写只用来分辨触发条件，不是置信度。

## 之前试过、不行的（别重复踩）

- 现有信号取反：全新数据 t=-5.16 说明追势方向系统性错，但取反后毛 +0.074% < 成本 0.10%，最好也就打平
- 12 种筛法（强度分档 5、结构性过滤 5、反转、每天只取第一个）：无一改善
- 改 5 分钟周期：-0.039%、t=-0.59，只是从「稳定错」变成「和零没区别」
- RSI 极值反转（胜率 58%）：趋势日会连续逆势标注，09-21 往一波 +9.5% 的上涨里连报 4 个 SELL
- RVOL 日过滤：论文里那个是**横截面选股**（几千只里挑今天有事的 20 只），盯固定标的用不上

参考 Zarattini/Barbon/Aziz 的 ORB 研究：不筛票 Sharpe 0.48 跑输大盘，按相对成交量筛出「Stocks in Play」后 Sharpe 2.81 —— *"abnormal participation, not the breakout pattern alone, drove profitability"*。

## 设计

每次轮询重新拉全天 K 线、整段重算标注，进程内不留可变状态。盘中任何时刻重启，重建结果与一直开着完全一致。
