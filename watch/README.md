# 盯盘

盘中只读 OpenD 行情，按标的打信号日志。**不下单。** 与 `custody` 主线（0DTE 择时）独立，不进策略注册表。

## 用法

```bash
/opt/futu-opend/venv/bin/python watch/smc_watch.py                          # 默认标的
/opt/futu-opend/venv/bin/python watch/smc_watch.py HK.02513 HK.09988 HK.01810
/opt/futu-opend/venv/bin/python watch/smc_watch.py SZ.300795                # A 股走腾讯 1 分钟 K 线
```

A 股代码写成 `SZ.300795`、`SH.600519` 或 6 位数字。行情来自腾讯财经的公开 1 分钟 K 线，不经过 OpenD。信号规则和港股相同。港股仍走 OpenD。

每个标的自己一块，当天信号从早到晚全留在这块里，不截断。刷新时只改有变化的行：报价变了就改这一行，新信号补在该标的自己的列表末尾，不会串到别的标的下面。加粗大写 `B`/`S` 是**价位细**（当日平均每根 K 线 ≥ 5 个价位）时的标注，暗色小写 `b`/`s` 是其余的；字母后面带 `~` 的是**价位受限**（不到 2 个价位）时的标注，照常显示，但历史上略偏反向。后面的 `1.4x` 是量比，`D+`/`D-` 是日线背景（见下）。表头的 `tpb` 是当日至今平均每根 K 线跨几个价位。窗口请拉高到能放下全部行，否则终端只会露出下面几只。

```
HK.02513  智谱   753.00  -906bp  vwap-379  rsi38.4  0.2x  tpb5.6 n150
  09:55 S BOS+FVG    783.50  1.4x  D- inv 805.50
  11:32 S FVG        755.50  0.2x  D+ inv 758.50
HK.01810  小米    50.10   +42bp  vwap+12   rsi55.0  0.8x  tpb0.7 n150
  10:21 b~BOS          50.15    1.2x  inv 49.95
```

管道输出（非 TTY）时不画看板，只打 JSON，方便 `| jq`。日志写 `watch/logs/<日期>.log`，每行带 `code`。

## 规则

**方向**（沿用最早那版）：`close` vs 当日 VWAP、EMA9/21、RSI14。

**触发**：

| 触发 | 含义 |
|---|---|
| `BOS` | 收盘突破左右各 3 根都确认的摆动点（结构突破） |
| `FVG` | 三根公允价值缺口，宽度 ≥ 0.25 × ATR14 |
| `SWEEP` | 影线扫穿确认摆动点后收回（流动性狩猎） |

**价位闸**（2026-09-24，研究 W2，见 [studies/watch_signal](../studies/watch_signal/README.md)）：

`tpb` = 当日至今平均每根 1m K 线的高低差 ÷ 当时价位（港股按交易所价位表，A 股 0.01），09:30 竞价那根不算。

| tpb | 看板 | 为什么 |
|---|---|---|
| < 2 | 暗色，带 `~` | 一根 K 线只跨 0～1 跳时，「突破」常是成交从买一翻到卖一。这些标注样本外 d1f30 −1.88bp、t=−6.6：统计上确实偏反向，但只有约 0.2 个价位，所以降级显示、不隐藏 |
| 2 ～ 5 | 暗色小写 `b`/`s` | 与抛硬币无显著差异 |
| ≥ 5 | 加粗大写 `B`/`S` | 样本外 +4.18bp、t=+2.0，可能略正 |

开盘前 25 根不标注，同方向同档（原来的普通 / 带量两档，只用于去重）15 根内不重复。标注带 `失效`（多头取最近确认摆动低点）。

原来的「带量」档（当根量 ≥ 1.5 × 前 20 根均量且在当日区间的顺位半区）不再决定加粗：它被量出不比普通档准。

**日线背景 `D+` / `D-`**（研究 W6，已通过验证）：`D+` = 标注方向与近 5 个交易日涨跌相反，且还没突破昨日高点（买）/ 昨日低点（卖）。
只用昨天及更早的日 K。验证段（2026-08-17 → 09-23）价位细的标注持有到收盘：`D+` +17.6bp（t=+2.5），`D-` −14.7bp（t=−2.8），
买卖两侧都成立。意思是：**连涨了一周、又刚突破昨日高点的 `B`，当天后面多半走不远**。它仍低于往返成本，是区分好坏的背景，不删任何标注；
取不到日线（接口失败）时不显示，标注照出。港股日 K 走 OpenD（只占订阅额度），A 股走腾讯日 K。

资金流分数（研究 W4）已撤下：单日测试里资金流同向的标注并不更准，且 72% 的标注本来就同向，它主要在复述「价格刚动过」。见 `studies/watch_signal/reports/FLOW_2026-09-24_CN.md`。

## 价位分层的实测（W2）

140 只港股通，下一根收盘入场、30 根后平（d1f30），t 按交易日聚类。训练 2026-06-01 → 08-14 定阈值，
**样本外 2025-12-01 → 2026-05-29（15,870 个标的-日，之前从未用过）**：

| | 个/标的-日 | d1f30 | 命中 | t |
|---|---|---|---|---|
| 改前全部标注 | 15.28 | −1.37bp | 47.2% | −4.5 |
| `~`（tpb < 2） | 11.42 | −1.88bp | 46.6% | −6.6 |
| 保留（tpb ≥ 2） | 3.86 | +0.04bp | 48.6% | +0.1 |
| 加粗（tpb ≥ 5） | 0.59 | +4.18bp | 49.5% | +2.0 |

常盯的：智谱 tpb≈5.4、MiniMax≈5.7（一条没被闸，保留的样本外 +15.9bp / +7.1bp）；腾讯≈2.4、阿里≈2.0（大部分保留）；
小米≈0.7（基本整天静默，它的标注训练段 −4.2bp、样本外 +1.1bp，本来就是噪声）。

**这仍然不是能赚钱的证明**：保留下来的标注方向上与抛硬币无显著差异，港股往返成本（价差 + 印花税）远大于这些毛收益。
`~` 的作用是提醒那 3/4 的标注略偏反向；它们与其余标注的差距不到 2bp，所以不隐藏。

### 带量 ≠ 更准

**「带量」那档在每一个格子里都不优于「普通」档**，胜率、均值、盈亏比都是。它只是更罕见。

之前只用 3 个标的时曾量出带量档盈亏比 1.56（vs 普通 1.26），加入 MiniMax（HK.00100）之后这个优势消失——MiniMax 单独看：普通 -0.001%（盈亏比 1.19）、带量 -0.464%（盈亏比 0.79）。那次是 138 个样本上的噪声。

**所以「带量」标签说的是「触发时有量且位置顺」，不是「更可靠」。** 大写小写只用来分辨触发条件，不是置信度。

## 之前试过、不行的（别重复踩）

- 现有信号取反：全新数据 t=-5.16 说明追势方向系统性错，但取反后毛 +0.074% < 成本 0.10%，最好也就打平（W2 补注：这个「系统性错」只在 tpb < 2 的标的上成立）
- 相对恒指 5 分钟超涨超跌取反（W1）：全样本 t=+6.6 过了门槛，但优势只在价位粗的标的上、以价位计只有 0.29 跳，延后 10 根入场就消失。不采用
- 价位细的标的上：多尺度动量 / 反转、VWAP 偏离、RSI、量比、RVOL 分层、日内动量（开盘段预测收盘段）、时段——都排不出显著的 30 分钟方向
- 12 种筛法（强度分档 5、结构性过滤 5、反转、每天只取第一个）：无一改善
- 改 5 分钟周期：-0.039%、t=-0.59，只是从「稳定错」变成「和零没区别」
- RSI 极值反转（胜率 58%）：趋势日会连续逆势标注，09-21 往一波 +9.5% 的上涨里连报 4 个 SELL
- RVOL 日过滤：论文里那个是**横截面选股**（几千只里挑今天有事的 20 只），盯固定标的用不上

参考 Zarattini/Barbon/Aziz 的 ORB 研究：不筛票 Sharpe 0.48 跑输大盘，按相对成交量筛出「Stocks in Play」后 Sharpe 2.81 —— *"abnormal participation, not the breakout pattern alone, drove profitability"*。

## 设计

每次轮询重新拉全天 K 线、整段重算标注，进程内不留可变状态。盘中任何时刻重启，重建结果与一直开着完全一致。
