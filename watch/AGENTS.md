# watch 规范：AH 股实时盯盘

> 先读根目录 [AGENTS.md](../AGENTS.md)。本文件只写这项能力的边界与规则；用法、信号定义和实测数字在 [README.md](README.md)。

## 边界

- 只读行情、只打标注，**不下单**，不进 custody 策略注册表，与 0DTE 主线独立。
- 盯用户给定的几只标的：港股走 OpenD（`get_cur_kline`，只占订阅额度，不耗历史 K 线额度）；A 股走腾讯公开 K 线，不经过 OpenD。
- 无状态：每次轮询按当天已完成的 1m K 线整段重算，盘中任何时刻重启结果必须一致；正在形成的那根不参与。
- 输出：TTY 画按标的分块的看板；非 TTY 每行一个 JSON（不得混入其他 stdout 输出）；日志写 `watch/logs/`（不进 git）。

## 改信号的规矩

- 信号规则的任何改动（新触发、新标记、新过滤、改阈值、改加粗）都要先在 `studies/watch_signal/` 预登记并通过验证，结果写进该目录的报告与 [README.md](README.md)。
- 港股 1m 研究必须按每根 K 线跨过的价位数（`tpb`）分层报告，并用下一根收盘入场（必要时看延后入场的衰减）；否则会把价位离散化误当成信号。
- **不隐藏标注**：证据只支持降级（暗色、`~`）或加标记（`D+`/`D-`），不支持删掉整类标注。
- 无法回测的数据（资金流、盘口、逐笔等）只能做**可选**的附加评分：取不到时标注照常产出，不得成为出信号的前提。
- 看板上的每个标记都要能在 README 里找到它的验证数字；未验证的东西要么不上，要么明确标「未验证」。

## 修改与验证

- 运行时只用标准库（`futu-api` 除外）。
- 改动后跑 `python3 watch/test_watch.py`；改了规则还要用 `studies/watch_signal/code/` 里的复刻核对脚本确认实现与研究判定逐条一致。
