# watch：AH 股实时盯盘

> 全仓库规则见 [../AGENTS.md](../AGENTS.md)；用法、信号定义和实测数字见 [README.md](README.md)。

## 边界

- 只读、只标注，不下单，不进 custody 注册表。港股走 OpenD（只占订阅额度），A 股走腾讯公开 K 线。
- 无状态：每次轮询按当天已完成的 1m 整段重算，重启结果一致。
- 非 TTY 输出每行一个 JSON，stdout 不混别的东西。

## 改信号

- 任何信号改动（触发、标记、阈值、加粗）先在 `studies/watch_signal/` 预登记并通过验证；看板上的每个标记都要能在 README 找到验证数字。
- 港股 1m 按每根跨几个价位（`tpb`）分层评估，用下一根收盘入场。
- 不隐藏标注：只降级（暗色、`~`）或加标记（`D+`/`D-`）。
- 回测不了的数据（资金流、盘口、逐笔）只能做可选评分，取不到时标注照出。
- 改了规则，用 `studies/watch_signal/code/` 的复刻核对脚本确认实现与研究逐条一致。
